01 — A decisão que muda tudo

Por que Tauri, e não Electron

A maioria dos apps de terminal "modernos" carrega um Chromium inteiro só para desenhar caixas de texto. JARVIS usa o WebView2 que o Windows 11 já tem instalado — e um núcleo em Rust puro para tudo que precisa de velocidade de verdade.

02 — O que já funciona

Uma central, não mais um terminal

Cada peça foi construída para o dia a dia de quem vive dentro do terminal.

Motor de PTY em Rust

Criar, escrever, redimensionar, matar, listar e restaurar sessões falando direto com o ConPTY do Windows. Terminal na tela com xterm.js acelerado por WebGL.

shells: ["pwsh 7", "PowerShell", "CMD", "Git Bash", "WSL"]

Abas e painéis

Reordenáveis por arraste, splits horizontais e verticais em árvore, divisores arrastáveis e reinício de shell sem perder o painel.

Workspaces

Uma pasta de projeto vira um workspace com nome e cor. Terminais novos nascem no diretório certo e lembram o shell preferido.

Agente de IA com contexto real

Chat com streaming token a token, falando com Ollama, OpenAI, Anthropic ou Gemini. O agente recebe a pasta do workspace, o shell ativo e as últimas linhas visíveis do terminal — cole um erro de build e pergunte "o que é isso?". Blocos de código sugeridos rodam direto no terminal ativo.

04 — Detalhes que só importam quando dão errado

Construído por gente que leu o manual do ConPTY até o fim

Um punhado dos problemas reais que apareceram no caminho — e como foram resolvidos.

O ConPTY segura o processo filho até alguém responder

O conhost manda uma consulta de posição de cursor e bloqueia o filho até ser respondido. O backend responde ao handshake no instante em que ele aparece, para nenhuma aba nascer congelada.

Um chunk de HTTP não é uma linha

Respostas de IA chegam picadas por tamanho de pacote — um caractere acentuado pode ter seus bytes divididos entre chunks. Um buffer de bytes garante que só linhas completas sejam entregues.

Cancelar precisa acordar a leitura, não só marcar uma flag

Uma flag consultada entre chunks não tem efeito num fluxo parado. O cancelamento usa um Notify que interrompe a espera na hora, com watchdog de inatividade como rede de segurança.

Config é salvo por fatias, não inteiro

Cada tela grava só a sua fatia do estado, com merge sob lock no backend — assim duas telas gravando ao mesmo tempo não se apagam.

06 — Perguntas

Antes de instalar

É de graça mesmo?

Sim. JARVIS é código aberto sob os termos do repositório no GitHub. Você pode instalar, usar e ler cada linha do que roda na sua máquina.

Preciso de uma chave de API para usar?

Não. O agente de IA funciona com Ollama rodando localmente na sua máquina — sem custo e sem dados saindo do seu computador. Se preferir, conecte OpenAI, Anthropic ou Gemini com sua própria chave.

Funciona em macOS ou Linux?

Hoje o motor de PTY fala diretamente com o ConPTY do Windows, então o foco é Windows 11. O código é aberto — contribuições para outras plataformas são bem-vindas.

O JARVIS manda meus dados para algum servidor?

Não há telemetria. O que roda localmente fica local; o que sai é só o que você mesmo envia para o provedor de IA que escolheu conectar.

Como desinstalo?

Como qualquer app Windows normal: Configurações → Aplicativos → JARVIS → Desinstalar. O instalador NSIS cuida de remover tudo.
